# Сайт-каталог книг

Статический сайт-каталог книг.
Проект генерирует HTML-страницы из `meta_data.json` с помощью Jinja2 и разбивает каталог на страницы с пагинацией.

## Опубликованный сайт

(Сам сайт)[https://remik202.github.io/library_layout/]

## Запуск

1. Установить зависимости:
   `pip install -r requirements.txt`
2. Сгенерировать страницы:
   `python render_website.py`
3. Открыть:
   `http://127.0.0.1:8000`

## Открыть локально

1. Скачайте проект и распакуйте у себя на ПК.
2. Откройте папку проекта:
   `С:\.....\library_layout`
2. Зайдите в папку `pages`.
3. Откройте файл `index1.html` в любом браузере.
